# Финальная оценка KuKi: протокол до открытия test

29 сентября 2026. Разработка завершена прямым решением пользователя. Ровно семь систем: L1 ST5 dropout0.3 epoch16; L2 ST3 l2-only epoch8; L3 ST3 l3-only epoch13; ST3 joint200 epoch8; ST6 4:1 epoch16; замороженные ST4 control epoch12 и families epoch1. Точные пути, SHA256 checkpoint, dev-метрики, конфигурации и пороги — в manifest.json. L3-контроль согласован с исходным сравнением ST3; детектор ST2 является общей фиксированной зависимостью, не восьмым кандидатом.

Test открывается один раз для этой серии. Семь систем не переобучаются, не ранжируются для последующей настройки и не заменяются. Обе задачи совместной модели используют один checkpoint. Все исходные артефакты сохраняются. Ошибки реализации разрешено исправлять с записью причины, но решения модели, пороги и состав сравнения после открытия test неизменны.

Основные показатели: L1 article-balanced macro-F1 при заданных человеческих границах и argmax; L2 Brier по индивидуальным ответам с равным весом статьи/фрейма; L3 условный article-mean F1 с собственным сохранённым dev-порогом и argmax fallback; L3 автоматический exact-F1, одинаковый fixed decoder alpha=2, threshold=-5.172313813576109, top500 кандидатов и top100 выходов. Overlap-F1 — дополнительный показатель. Никакой повторной калибровки. ST4 сохраняет L3 родителя без изменений.

Сравнения: ST3−L2 по Brier и ST3−L3 по двум L3 F1; ST6−L1 по F1 и ST6−L2 по Brier; обе ST4−ST3 по Brier и ST4 families−control (изолированный вклад вероятностей семейств). Для всех основных метрик показать 95% percentile интервалы, для разностей — парный bootstrap 10000 повторов, seed42, по статьям с сохранением всех ответов/фрагментов внутри статьи. L1 пересчитывается из суммарных взвешенных confusion matrices, а не усреднением F1 статей; статьи без L1 не входят в его метрику. Условный L3 исключает статьи/ответы без размеченных фрагментов; автоматический L3 оценивает все статьи. Если есть связанные дубли статей, сохранять группу при ресэмплинге. Интервалы не учитывают случайность обучения и не корректируются за несколько сравнений; это описательная неопределённость, не доказательство универсального превосходства.

Сохранение направления улучшения Brier ST3 проверяет разработческий вывод; если интервал разности включает ноль, говорить о сохранении направления, но неопределённости преимущества. Если выигрыш отсутствует, явно указать отсутствие независимого подтверждения. ST4 требует улучшения families относительно ST3 и control; интервалы определяют уверенность. Для ST6 сохранить прежний критерий: ΔF1≥−0.01, ΔBrier≤0.003, и ΔF1≥0.01 либо ΔBrier≤−0.003 относительно test-контролей. Ни критерии, ни модель после test не меняются.

Одна серия inference с записью вероятностей и независимой CPU-проверкой метрик. До test технический replay выбранных систем на dev должен совпасть с сохранёнными прогнозами. Новых optimizer steps нет. Итог: единый отчёт, три исследовательских вывода, ограничения и приложение истории; после отчёта исследование завершено без нового поиска.
