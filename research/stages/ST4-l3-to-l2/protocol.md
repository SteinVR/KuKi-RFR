# ST4 — протокол первой ограниченной серии

29 сентября 2026. Прямое поручение пользователя: перейти к ST4. Протокол фиксируется до обучения. Это разработческое сравнение механизмов, не итоговая проверка научной гипотезы.

## Вопрос и матрица

Даёт ли передача автоматически найденной риторики пользу сверх общего энкодера и дополнительных вычислений? Все шесть веток начинают с выбранного joint200 ST3 (эпоха 8, 152 updates, 1160 предъявлений статьи). Оптимизатор и расписание одинаково сбрасываются; состояние исторического optimizer не используется.

| Ветка | Дополнительный путь |
|---|---|
| continue | отсутствует |
| self | residual MLP по собственному pooled-представлению статьи |
| hidden | среднее скрытых представлений предложенных фрагментов, без явных семейств/геометрии/оценки детектора |
| uniform | равномерное среднее сообщений: скрытое представление + вероятности 6 семейств + относительные начало/конец + sigmoid оценки детектора |
| confidence | те же сообщения; нормированный вес sigmoid(detector_logit) × max(p_family) |
| contextual | те же сообщения; scaled dot-product attention, query от pooled статьи, key от сообщения |

Contextual — адаптация стандартного внимания, не новый научный метод ([Vaswani et al.](https://arxiv.org/abs/1706.03762)). Проверяем, полезна ли контекстная агрегация в этой задаче, и отличается ли она от отбора по уверенности. Веса attention не считаются объяснением причинной применимости. В этой первой серии нет поиска гиперпараметров и дополнительных seed.

Общий предел 3600 секунд процессов с GPU: технические проверки до 120с, три OOF-детектора до 500с каждый, шесть продолжений до 300с каждое, финальная проверка до 180с. Если профиль не подтверждает выполнимость, матрица корректируется до первого научного fit. Не расширять лимит; неполную серию так и обозначить.

## Происхождение кандидатов

Внешние train/dev/test и группы неизменны, 145/31/31. Группы train детерминированно распределяются по трём внутренним fold (seed42). Для каждой исключённой группы отдельный GlobalPointer обучается с чистых закреплённых базовых весов только на остальных train-группах; он не получает dev/test и не выбирает checkpoint по исключённым статьям. Фиксированные 13 эпох, LR2e-4/1e-3, warmup10%, та же архитектура и loss ST2. Выбран последний checkpoint. 13 эпох взяты как инженерный режим из исторического E3; это не независимый подбор гиперпараметров внутри fold. Сохранять manifest, группы обучения/предсказания, хэши, состояния и top500.

Для dev используется существующий full-train детектор E3, выбранный ранее на этом dev (эпоха13); происхождение сохранено. Он не видел dev при обучении, но выбор на dev — часть многократной разработки, не независимая оценка. Его расписание было рассчитано на16эпох, OOF — на13; различие явно сохраняется. Отдельная настройка OOF по dev запрещена. Test не возвращается загрузчиком и не токенизируется.

Для сообщений используются все top500 предложений; человеческие границы к ним не добавляются. Предсказания семейств вычисляет текущая совместная сеть, а не отдельный обученный на всей train источник. OOF нужен внешнему фиксированному генератору; внутренний совместно обучаемый классификатор не является последовательным stacking. При финальной train-оценке используется тот же OOF-генератор; train/dev не сопоставляются как одинаковое качество генерации. Автоматический dev L3 оценивается прежним decoder на прежних dev-кандидатах.

## Механизм и градиенты

Представление span — среднее его символьных скрытых признаков (64). Семейства — sigmoid текущего L3-классификатора в детерминированном режиме его головы без dropout. Положение — start/N,end/N; sigmoid detector score — некалиброванная оценка, не доказанная вероятность.

Выход L2: z_base + Δz. residual projection заканчивается нулевой линейной головой, поэтому все ветки в начале воспроизводят ST3. Ошибка L2 = 0,5 BCE(z_base) + 0,5 BCE(z_base+Δz), L3 вес2; у continue это ровно прежняя L2 BCE. Сохраняем прямой базовый выход и измеряем отключение сообщения после обучения.

Вероятности семейств в сообщении detached: ошибка L2 не обновляет span-classifier через их значения; скрытые span-признаки и query получают градиент L2. Общий энкодер остаётся обучаемым через обе задачи. Предложения и их оценки фиксированы. Это один выбранный режим, без перебора градиентных путей. Условный L3 loss по человеческим фрагментам отдельно, с прежним усреднением по ответам и статьям. RNG dropout span-head изолирован от encoder dropout; новые residual-модули без dropout.

Все residual-модули инициализируются в одинаковом порядке, неиспользуемые замораживаются. Self контролирует дополнительное вычисление, hidden — семантические компоненты при тех же позициях. Размеры/число параметров различаются и учитываются; равенство FLOPs не заявляется.

## Обучение и выбор

По 8 дополнительных эпох, 152 updates, 1160 предъявлений, accumulation8 (остаток делится на фактическое число). LoRA5e-5, головы2,5e-4; новые модули не получают отдельного повышенного LR. AdamW decay0,01, clip1, warmup15/152, линейное снижение, seed42. Это ограниченное продолжение зрелого checkpoint, не обучение с нуля. Порядок статей общий; начинается с позиции epoch8 исторической последовательности. Нет ранней остановки по метрике.

Во всех ветках minimum dev Brier из начального состояния и восьми эпох (равенство — раннее); сохраняются start/best/last, одинаковый лимит выбора. Кроме best оценивается last с одинаковым числом обновлений. Критерий интереса относительно нового continue: ΔBrier ≤−0,003, потеря условного L3 F1 ≤0,02 и сквозного exact-F1 ≤0,005. Дополнительно сравниваем с неизменным ST3, self и hidden; выигрыш лишь у слабого continue не доказывает пользу. Выбор основного варианта по Brier среди uniform/confidence/contextual, без смены критерия после результатов.

Метрики: L2 Brier по индивидуальным ответам с равным весом статьи/фрейма; macro/micro-F1 при0,5. L3 условный F1 с прежним dev-подбором порога, fixed exact/overlap-F1, AP, пустые ответы. Исторический decoder alpha2/threshold−5.172313813576109/cap100 неизменен. Для best: train/dev; для last: dev. Диагностика выключения сообщения и перемешивания семантических компонентов между предложениями внутри статьи не меняет выбранные веса/пороги. По каждой статье сохранить улучшение/ухудшение, по источникам и фреймам — описательные срезы. Парный bootstrap10000 по группам статей описательный и не устраняет выбор по dev/один seed.

## Проверки

До серии: начальная эквивалентность ST3; отсутствие gold в message forward; реальные градиенты и обновления новых параметров; изоляция detached вероятностей; неизменность frozen base; корректная нормировка; точное восстановление следующего update с RNG/AdamW/scheduler; профиль длинных статей. OOF-fold не пересекаются по группам; покрытие train ровно один раз. Все fit сохраняют RNG/optimizer/scheduler/order/position после updates. Финально — свежая загрузка best, независимый CPU-пересчёт, хэши исторических входов, self-review. ST5/ST6 автоматически не запускаются.
