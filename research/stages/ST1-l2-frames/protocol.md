# ST1 — протокол до просмотра качества

28 сентября 2026. Продолжение ST0; среда и разбиение сохранены.

- Train: 145 статей; dev: 31. Test исключён из токенизации, fit, прогнозов и анализа; общий файл проверяется по хешу и читается для отбора разрешённых записей.
- Частотный baseline: среднее долей голосов по train-статьям. Одна статья — один вес.
- Линейный baseline: TF-IDF word (1,2) / char_wb (3,5), словарь только train, равные веса двух нормированных пространств; логистическая регрессия C=10 без поиска. Мягкие цели реализованы двумя бинарными копиями строки с весами q и 1−q, где q — доля голосов внутри статьи; общий вес статьи 1.
- RuModernBERT-base: точные настройки в `configs/pilot-v1.json`, новая LoRA и head. До 8 эпох/152 обновлений, накопление 8 статей; последний неполный батч делится на фактическое число статей.
- Основной выбор: минимальный dev Brier относительно индивидуальных бинарных ответов с равным весом статей и 14 фреймов. Метрика дополнительно разлагается на MSE относительно долей голосов и наблюдаемое разногласие.
- Лучшее состояние — абсолютный минимум Brier; patience 3 эпохи отсчитывается от улучшения минимум 0,0001. Эти два правила различаются сознательно.
- F1: strict majority (>0,5 доли голосов, ничья отрицательна), прогноз ≥0,5, пустой набор разрешён, zero_division=0. Порог в этом этапе не настраивается. Редкие классы и число голосов показаны отдельно.
- Полный checkpoint после каждого обновления и после оценки эпохи; сохраняются RNG, порядок, позиция, оптимизатор, scheduler, patience, история и счётчики. Контрольные суммы кода, данных, uv.lock и конфигураций проверяются при продолжении.
- Сначала один нейросетевой пилот и фиксированный линейный baseline. Не более трёх обучаемых конфигураций суммарно в ST1; резерв одного варианта используется только при конкретном основании из dev-диагностики. Частотная оценка не имеет подбираемых параметров.
- Начальная конечная серия: ≤10 минут CPU baseline и ≤30 минут пилот, общий предел ST1 вычислений 60 минут, включая технические проверки. После первой эпохи пересчитать стоимость; ни ST2, ни итоговый тест автоматически не запускаются.
- Сравнения на dev — разработческие, после выбора эпохи/варианта они не подтверждают обобщение. Парный bootstrap фиксированных прогнозов по группам статей допускается как описательная оценка неопределённости, без поправки на подбор и вариативность обучения. Один seed 42.

Проверки перед запуском: 16 тестов проходят, включая метрики/ничьи, веса статей, частичное накопление, точное восстановление обучения со случайным dropout через границы эпох и неполный батч, защиту групп и хешей. Исходные аннотации не меняются.
